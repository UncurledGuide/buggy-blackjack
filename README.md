A simple Blackjack game you play in your terminal.

## Requirements

- Python 2.7 or newer

## How to run

```
python3 blackjack.py
```

## Features

- 6-deck shoe, reshuffled automatically
- Hit, stand, **double down** and **split**
- Dealer hits on soft 17
- Blackjack pays 3:2
- High scores saved between games

## How to play

You start with $500. Place a bet, then type `hit` or `stand`.
Get closer to 21 than the dealer without going over.
